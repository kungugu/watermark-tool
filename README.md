# BMP Watermarker

## 📖 Описание проекта

**BMP Watermarker** — это консольное приложение на языке C++, предназначенное для наложения цифрового водяного знака (второго изображения) на исходное изображение в формате BMP и сохранения результата в новый файл. 


## Возможности

* Чтение и парсинг растровых изображений формата BMP (24-bit).
* Наложение водяного знака (изображения) на исходное изображение.
* Сохранение итогового изображения в новый BMP-файл без потери качества исходных пикселей.
* Обработка ошибок (неверный формат файла, несовпадение размеров, отсутствие файлов).

## Требования

Для сборки и запуска проекта вам понадобятся:
* Компилятор C++ с поддержкой стандарта C++17 или выше (GCC, Clang, MSVC).
* CMake (версии 3.15 или выше).
* Git.
